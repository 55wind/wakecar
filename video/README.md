# 일어나차 심사위원 소개 영상

180초, 1920 × 1080, 30fps 가로형 영상입니다. 한국어 자막과 앱 원작 음악 및 효과음을 사용하며, 음성 내레이션은 없습니다.

## 산출물

- [최종 소개 영상](output/wakecar-jury-hallmark-3min.mp4): 자막을 화면에 포함한 최종 영상, H.264 영상과 AAC 스테레오 음원
- [한국어 자막](output/wakecar-jury-ko.srt): 별도 한국어 자막
- [표지 이미지](output/wakecar-cover.jpg): 영상 표지

앱의 밤하늘과 새벽 색상, 언덕 장면, 원작 3D 캐릭터를 바탕으로 제작했습니다. 기능 소개 장면은 실제 에뮬레이터 캡처에 강조 표시를 추가한 모션 그래픽이며, 실시간 화면 녹화는 아닙니다. 시연 모드에서 촬영한 화면을 포함하고, 설명의 시간은 일반 모드 기준입니다.

## 사용 자산

- 실제 화면: `../docs/screens/`
- 캐릭터: `../app/src/main/assets/chars/`
- 앱 아이콘: `../design/character-v2/3d/out/app_icon_512.png`
- 음악과 효과음: `../app/src/main/res/raw/`의 수면 피아노, 앰비언트, 파도, 해 뜨는 피아노 알람, 오르골 알람, 시작과 완료 효과음
- 영상 글꼴: 로컬 Pretendard Variable. 재생용 MP4에 영상으로 포함하며 글꼴 파일은 배포하지 않습니다. 재생성 시 `WAKECAR_FONT`로 글꼴을 지정할 수 있고, 지정하지 않으면 macOS 시스템 한국어 글꼴을 사용합니다.

## 다시 만들기

필수 도구: Python 3, Pillow, NumPy, Node.js, ffmpeg, Playwright Chromium.

```sh
cd video
npm ci
npx playwright-core install chromium
python3 audio.py
node render.mjs --preview
node render.mjs
python3 finish.py
```

`scenes.json`에서 문구, 장면 순서, 길이를 수정하고, `film.html`에서 배치와 모션을 수정합니다. 최종 길이를 바꾸는 경우 `film.html`의 전체 진행률과 끝 페이드, `finish.py`의 180초 설정도 함께 조정합니다.

`build/`와 설치된 의존성은 Git에서 제외합니다. `output/`에서는 최종 Hallmark 영상, 한국어 자막과 표지만 저장소에 포함하고, 이전 버전과 기타 산출물은 제외합니다. 영상 내 성능 및 효과 수치는 제시하지 않으며, 실차 음량과 성능의 후속 확인이 필요하다는 구현 범위를 표시했습니다.

## Hallmark 적용

앱의 실제 색상과 원작 자산을 유지하는 브랜드 방식으로 적용했습니다. 반복 카드와 제목 위의 장식 라벨을 제거하고, 미션은 좌우 반전 배치, 재알람은 전후 화면 병치, 휴식은 10분을 강조하는 배치로 바꿨습니다. 등받이 제어는 실제 제한인 2초, 10초, 3초를 크게 표시합니다. 소리 장면의 파형은 최종 앱 음원 믹스의 실제 RMS 값에서 가져옵니다.

`hallmark/tokens.css`가 Canvas와 미리보기 화면의 색상 및 글꼴을 함께 관리합니다. 미리보기 HTML에는 스크립트가 없어도 사용할 수 있는 영상 플레이어와 다운로드 링크가 있습니다.

Hallmark의 웹 UI 검사와 별도로, 실제 영상 프레임을 독립 검토했습니다. 웹 검사는 0 FAIL, 0 REFLEX이며, 남은 두 비교 경고는 이전 Canvas 코드의 좌표를 수치 정보로 오인한 것과 JavaScript 문자열까지 본문으로 센 것입니다. `scenes.json`의 기능 정보는 유지했습니다. 프레임 검토에서 지적한 미션 문장을 가로지르는 강조 테두리는 제거했습니다.
