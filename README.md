# 일어나차 (WakeCar)

현대자동차그룹 차량용 앱 개발 공모전(Code your App into Pleos App Market) 출품작 저장소.

## 앱 이름 및 한 줄 소개

- 앱 이름: 일어나차 (WakeCar)
- 한 줄 소개: 차 안에서 잠깐 자는 운전자를 정한 시각에 빛과 소리, 등받이로 깨우고, '깨어남 미션'으로 정말 깼는지 확인하는 '다시 잠들지 않는 차 안 낮잠' 앱입니다.

정차(기어 P, 속도 0) 중에만 동작합니다.

| 단계 | 차가 하는 일 |
|---|---|
| 자는 동안 | 기어 P와 문 닫힘을 확인하고 운전자가 "정차 중이에요. 낮잠 시작"을 눌러 시작합니다. 문이 잠겨 있지 않으면 잠그고 쉬도록 안내합니다. 등받이는 운전자가 직접 젖히고, 앱은 무드등과 화면을 어둡게 합니다 |
| 깨울 때 | 1단계 정한 시각 3분 전 조명을 서서히 밝힘 → 2단계 알람과 깨어남 미션 → 3단계(1분간 반응 없음) 바람과 알람을 세게, 켜 두었다면 등받이를 세우는 방향으로 조금씩 → 4단계(5분간 반응 없음) 알람 최대 |
| 깨어남 미션 | 알람은 화면을 한 번 눌러서는 꺼지지 않습니다. 브레이크 두 번 밟기, 와이퍼 한 번 켜기, 운전석 창문 내렸다 올리기 가운데 하나를 해야 멈춥니다. 몸이 불편하면 화면을 3초 길게 눌러 끕니다 |
| 다시 잠들기 방지 | 미션을 마친 뒤 3분 동안 아무 차량 조작이 없으면 다른 미션으로 다시 깨웁니다. 알람이 멈춘 뒤 '5분만 더'로 한 번 미룰 수 있습니다 |
| 다시 출발 | 짧은 말놀이(맞고 틀림은 따지지 않음) 뒤 10분 동안 바람을 쐬도록 권하고, 10분이 지나야 '출발할게'를 누를 수 있습니다 |

안전장치
- 자는 중 문이 열리거나 브레이크를 밟거나 기어가 P에서 벗어나거나 차가 움직이면 바로 끝냅니다.
- 차량 전원 차단 경고가 뜨거나 배터리가 기준 아래로 떨어지면 바로 깨웁니다.
- 앱은 등받이를 뒤로 젖히지 않습니다. '등받이 일으키기'는 기본 꺼짐이고, 켜면 세우는 방향으로만 한 번에 2초 이내, 모두 10초까지 움직이며 브레이크, 문, 화면 조작이 있으면 바로 멈춥니다.
- 주행 제어(시동, 잠금, 제동, 조향)는 쓰지 않습니다. 낮잠이 끝나면 무드등과 공조를 낮잠 전 상태로 되돌립니다.
- 효과를 재기 위한 기록(깨운 횟수, 다시 잠들어 한 번 더 깨운 비율, 권장 휴식을 채우고 출발한 비율)은 이 기기에만 저장하고 밖으로 보내지 않습니다.

## 실행 방법

1. Android Studio에서 이 폴더를 엽니다 (JDK 17, Gradle 8.10.2 wrapper, AGP 8.8.2).
2. Pleos Connect Emulator(Pleos_Connect_v2.1, API 34, Automotive, Cold boot, RAM 4GB)를 만들고 실행합니다.
3. `app` 구성을 에뮬레이터에 Run 합니다. 또는 `apk/` 폴더의 release APK를 `adb install -r`로 설치합니다.
4. Virtual Console을 엽니다: `adb forward tcp:8088 tcp:8088` 뒤 브라우저에서 `http://127.0.0.1:8088/`.
5. Virtual Console에서 기어를 P로 두고 문을 닫으면 "정차 중이에요. 낮잠 시작"이 켜집니다. 시연 모드를 켜면 낮잠 1분이 2초로 줄어듭니다.
6. 알람이 울리면 화면에 나온 미션을 Virtual Console로 수행합니다(브레이크 두 번, 와이퍼 Low, 운전석 창문 내렸다 올리기).
7. 속도 확인은 시작 화면의 "속도: 허용하면 확인해요"를 눌러 허용하면 켜집니다. 허용하지 않으면 기어 P로만 정차를 확인합니다.

명령줄:

```bash
./gradlew assembleDebug        # 디버그 APK
./gradlew installDebug         # 실행 중인 에뮬레이터에 설치
./gradlew testDebugUnitTest    # 낮잠 흐름 단위 테스트
```

## 테스트 환경 및 필요한 설정

- Pleos Connect Emulator 2.1.0 (시스템 이미지: API 34 "Pleos Connect v2.1.0 APIs")
- Vehicle SDK 2.3.2 (Brake, Door, Wiper, Window, EvBattery, Fuel, Safety, Seat, Light, HVAC), Android Automotive 표준 속성(GEAR_SELECTION, PERF_VEHICLE_SPEED)
- 차량 상태 변경은 Pleos Connect Virtual Console 사용
- 무드등, 풍량, 등받이 제어는 시작할 때 지원 여부를 확인하고, 지원하지 않는 환경에서는 건너뛰거나 화면 안내로 대신합니다
- 음성 안내는 Android 기본 TTS 엔진을 씁니다. 엔진이 없으면 알람과 화면 문구만 나옵니다
- 에뮬레이터는 등받이가 끝까지 젖혀진 값(0)에서 시작하므로, 등받이 일으키기를 보여 주려면 시연 전에 Virtual Console에서 등받이를 낮춰 둡니다
- `python tools/vc_test.py all`로 Virtual Console에 값을 넣어 가며 전체 흐름을 자동으로 돌려 볼 수 있습니다

## 저장소 구성

- `app/` 앱 모듈 (`kr.contest.wakecar`)
  - `core/` 낮잠 흐름 상태 기계와 익명 기록 (Android, 차량 API와 분리, 단위 테스트 포함)
  - `vehicle/` Pleos Vehicle SDK와 표준 차량 속성 연결
  - `audio/` 음성 안내, 알람
  - `ui/` 화면
  - `NapService` 낮잠 중 다른 화면으로 넘어가도 알람이 울리도록 앱을 살려 두는 서비스
- `docs/screens/` 에뮬레이터 화면 캡처
- `tools/` 에뮬레이터 자동 실행 스크립트
